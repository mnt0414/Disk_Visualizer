# SQLite schema v6

Phase 5のキャッシュ実行時状態を履歴として再現できるよう、`scan_entries`へ以下を追加する。

- `cache_runtime_state`: `stable`／`changing`／`unknown`

新規スキャンでは、キャッシュ分類された項目だけに状態を保存する。ファイルの最初のメタデータsnapshotと、保存直前の読み取り専用再観測を比較し、identity・論理サイズ・更新時刻のいずれかが変化した場合は`changing`、同一なら`stable`、比較材料が不足した場合は`unknown`とする。

`stable`は「別プロセスが使用していない」ことを保証しない。アプリはファイル内容を読まず、排他ロックも取得しない。

v5以前の履歴は再観測できないため、移行後も`NULL`のまま保持する。過去履歴へ`unknown`を補完せず、「未記録」と「観測したが不明」を区別する。v5からの移行前には整合したバックアップを作成する。
