## 使用中・変動中判定の方針

初期実装では、別プロセスがファイルを開いていることをmacOS／Windows共通の意味で断定しない。スキャン前後に取得できたファイルidentity、論理サイズ、更新時刻を比較し、変化を観測した場合だけ`changing`、同一の観測値を取得できた場合は`stable`、権限不足や再取得失敗など比較材料が不足する場合は`unknown`とする。

`stable`は「使用されていない」ことを保証しない。OS固有のロック・共有モード検査を追加する場合は、読み取り専用動作、通常アプリへの干渉回避、偽陽性・偽陰性、権限エラーを別途定義してから実装する。

パス再観測ヘルパーは通常ファイルだけを対象とし、シンボリックリンク、リパースポイント、ディレクトリ、消失済みパス、handle snapshot取得失敗を`unknown`へ倒す。ファイル内容は読み取らず、既存のOS別メタデータ取得処理を再利用する。

## 実行時状態の保存

キャッシュ分類された項目では、走査中に取得したfile identity・論理サイズ・更新時刻を最初の観測値とし、保存直前に同じパスを読み取り専用で再観測する。比較結果を`cache_runtime_state`へ保存し、`list_cache_entries`から返す。

SQLite v6では`stable`／`changing`／`unknown`だけを許可する。v5以前の履歴は再観測できないため`NULL`のまま保持し、「未記録」と「観測したが不明」を区別する。v5からの移行前には整合したバックアップを作成する。

Linux上の一時検証環境ではTauriが必要とするGTK／GDK開発ライブラリがないため`cargo test`を完走できなかった。ソースは`cargo fmt`済みで、macOS／Windowsの通常CIを最終検証基準とする。

## 観測状態の表示

アプリキャッシュ画面では、保存値を次の日本語ラベルで表示する。

- `stable`: 「変化なし」。観測中にメタデータの変化がなかっただけで、未使用を保証しない
- `changing`: 「変化を検出」。整理前にアプリの動作確認を促す
- `unknown`: 「判定できず」。比較材料が不足した状態
- `NULL`: 「未記録」。v5以前など、実行時状態を保存していない履歴

状態は色だけに依存せず、ラベルと展開説明を併記する。安全注記でも「変化なし」は未使用を意味しないことを明示する。

## 追加アプリ定義

カタログ`2026.08.2`でAdobe Media CacheとBlender Asset Library Cacheを追加した。

AdobeはmacOSの`~/Library/Application Support/Adobe/Common`とWindowsの`%APPDATA%/Adobe/Common`配下について、`Media Cache Files`と`Media Cache`だけを分類する。`Adobe/Common`全体や設定で変更された場所は分類しない。整理後は必要に応じてキャッシュが再生成され、次回の読み込みや再生が一時的に遅くなる可能性を表示する。

Blenderは公式資料のAsset Library索引キャッシュだけを分類する。macOSの`/Library/Caches/Blender`はファイルシステムルート基準の`systemCache`として解決し、Windowsは`%LOCALAPPDATA%/Blender Foundation/Blender/Cache`を使う。物理シミュレーション、レンダー一時データ、自動保存、外部キャッシュは対象外とする。

DaVinci ResolveとAutodesk Flameは保存場所がプロジェクト・ユーザー設定や共有ストレージ構成に依存するため、設定を読み取れるまで固定パス定義を追加しない。

## 保存済みキャッシュ分類query

UI向けqueryは完了済みのスキャンだけを対象とし、既定100件、最大500件の範囲でページングする。保存済みのカタログ版と現在の組み込みカタログ版が一致し、定義ID・定義版も一致する場合だけ、根拠、信頼度、再生成可否、整理時影響を含む定義詳細を返す。カタログ版が異なる履歴を現在の定義で読み替えない。

## アプリキャッシュ画面

保存済みスキャンの最新履歴を初期選択し、履歴セレクターから対象を切り替えられる。画面は`list_cache_entries`の先頭100件を読み込み、表示中の合計サイズ、アプリ名、分類、パス、信頼度、観測状態、根拠、再生成可否、整理時影響、カタログ版・定義版を表示する。

カタログ版または定義版が現在の組み込み定義と一致しない履歴は、現在の定義で読み替えず「保存済み定義」として表示する。読み込み中、エラー、保存履歴なし、候補なしを独立した状態として扱う。アプリ内からの削除・移動は提供せず、表示サイズが実際に解放できる容量を保証しないことを明記する。
