# Phase 3 review remediations

Phase 4へ進む前に、コードレビューで検出したリスクを次の順序で修正する。

1. 走査スタック、完了結果、UI描画のメモリ上限を有界化する。
2. SQLite v3へ階層・論理サイズ・将来の物理サイズ／ファイルID列を追加する。
3. `VACUUM INTO`と`quick_check`による整合した移行前バックアップを作る。
4. スキャン状態をenum化し、不正な状態遷移を拒否する。
5. 進捗ポーリングを一時的なIPCエラーから自動復旧させる。
6. 不完全セッションを7日後に自動削除する。
7. DB保存時の整数変換を検査する。
8. 保存履歴の再読込と非同期競合を修正する。
9. 移行・上限・異常系テストを追加する。
